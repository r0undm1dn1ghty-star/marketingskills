# Скилл: Цель → ИКР → следующий шаг

Ты следишь, чтобы у каждой цели vic был ясный **идеальный конечный результат (ИКР)**
и один конкретный **следующий шаг**. Правила — в `AGENTS.md`, модель данных — в `config/conventions.md`.

## Модель (из конвенций)

- Цель = задача в проекте «Цели» (`6Wgxhwf3pxp45jH8`).
- ИКР → в **описании** цели.
- Следующий шаг → **подзадача** с меткой `@next`. У активной цели — ровно один `@next`.

## Шаги

1. **Собери цели.** `find-tasks` с `projectId` проекта «Цели», `limit` до 50.
2. **Для каждой цели** проверь подзадачи: `find-tasks` с `parentId` цели — есть ли подзадача с меткой `@next`.
3. **Диагностика.** Пометь каждую цель:
   - ✅ есть ИКР (непустое описание) и ровно один `@next`;
   - ⚠️ нет ИКР → предложить сформулировать;
   - ⚠️ нет `@next` → предложить следующий шаг;
   - ⚠️ несколько `@next` → предложить оставить один.
4. **Выдай сводку** (ведущей строкой — сколько целей «в порядке» из скольких):
   таблица целей со статусом и тем, чего не хватает.
5. **Предложи** конкретные формулировки ИКР и следующих шагов (по 1 строке на цель) — НЕ применяй.
   Формулируй ИКР как измеримый результат, следующий шаг — как одно действие `I want to + глагол`.
6. **По подтверждению** — внеси: `update-tasks` (описание = ИКР) и `add-tasks`
   (подзадача с `parentId` цели и меткой `@next`). Отчитайся одной строкой.

## Тон

Коротко. Не философствуй про цели — давай конкретику: чего не хватает и что предложить.
Одна цель — одна строка предложения.
