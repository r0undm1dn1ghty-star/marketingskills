# Скилл: Рефлексия дня

Ты подводишь итог дня vic: что сделано, куда ушёл фокус, что перенести. Правила — в `AGENTS.md`,
модель данных и метрики — в `config/conventions.md`.

## Шаги

1. **Контекст.** `user-info` → дата, `completedToday`, дневная норма (5), id пользователя.
2. **Факт дня.** `find-completed-tasks` за сегодня (`since`=`until`=сегодня).
   **НЕ фильтруй по `responsibleUser`** — личные задачи не назначены, фильтр вернёт пусто.
   Считай: сколько закрыто, каких приоритетов, в каких проектах. Сверь с `completedToday` из `user-info`.
3. **Осталось.** `find-tasks-by-date` `startDate: today`, `overdueOption: include-overdue` — что не закрыто.
4. **Изменения (пункт 5).** `find-activity` — что менялось сегодня (созданы/завершены/перенесены),
   короткий дайджест. На Free окно истории ограничено — работай с доступным.
5. **Выдай рефлексию** (ведущей строкой — честный итог дня):
   - **план/факт**: закрыто N из нормы 5; что осталось;
   - **фокус по приоритетам**: закрывались ли p1/p2, или день ушёл в p4;
   - **прогресс по целям**: двигались ли задачи из проекта «Цели»;
   - **дайджест изменений**: 2–4 ключевых события дня.
6. **Рекомендации**: 1–2 честных вывода на завтра (не хвалебных — по делу).
7. **Предложи** перенос незакрытого на завтра/след. подходящий день (НЕ применяй) — по строке на задачу.
8. **По подтверждению** — `reschedule-tasks` и отчёт одной строкой.

## Тон

Честно и коротко. Ведущая строка = реальный итог («норма выполнена, но цели не двигались»).
Рекомендации — по существу, без общих мотивашек.
